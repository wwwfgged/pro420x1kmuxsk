# Muzik420

Muzik420 — музичний плеєр для Windows і мобільних пристроїв. Він керує локальною музичною бібліотекою, відтворює треки й плейлісти, завантажує музику за підтримуваними посиланнями YouTube і TikTok та створює резервні копії в Google Drive.

## Можливості

- Відтворення локальних аудіофайлів і керування плейлістами.
- Завантаження музики за посиланнями YouTube і TikTok.
- Персоналізація вигляду: теми, фон та інші параметри плеєра.
- Резервне копіювання та відновлення бібліотеки через Google Drive.
- Збирання для Windows, Android, iOS, macOS і Linux.

## Технології та авторство

Основна мова — **Dart**, інтерфейс і кросплатформна логіка створені на **Flutter**. Платформні частини використовують Kotlin на Android, Swift на Apple-платформах і C++ для Windows та Linux.

Проєкт підтримує автор репозиторію (`wwwfgged`). У вибраних задачах розробки й документації допомагали AI-помічники Claude та OpenAI Codex.

## Збирання

Передумови та покрокові команди збирання наведені у [BUILDING.md](BUILDING.md). Основна команда для Windows:

```powershell
flutter pub get
flutter build windows --release
```

Застосунок Windows і потрібні йому файли з'являться у `build/windows/x64/runner/Release/`. Для запуску або передавання збірки зберігай усю папку разом.
