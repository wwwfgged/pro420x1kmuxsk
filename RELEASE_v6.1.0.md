```markdown
## 🎵 Оновлення v6.1.0 — Windows / Android / iOS

Цей реліз призначений для всіх платформ: **Windows**, **Android** та **iOS**.
Версія: **6.1.0** (build 6.1.0+1).

### Що змінено

- 🔙 **Повернуто старий дизайн плеєра.** Новий скляний стиль остаточно видалено — залишився тільки старий, стабільний інтерфейс (`MobileMiniPlayer` + `MobileFullPlayer`). Старий дизайн увімкнений за замовчуванням і не має перемикачів.
- 📐 **Виправлено верстку.** Мініплеєр і нижня навігація лежать у власних слотах `Scaffold` (`bottomSheet` + `bottomNavigationBar`), тому не перекривають список пісень — список гортається до останнього рядка. Враховано Safe Area та Dynamic Island на iPhone.
- 🍎 **iOS: перемикання треків при заблокованому екрані.** Черга тепер задається нативно через `AVQueuePlayer` (`setAudioSources` + `LoopMode.all`), тож музика продовжує грати й перемикатися, коли екран вимкнено. Додано `UIBackgroundModes = audio` у `Info.plist`.
- 🔢 **Версія 6.1.0 скрізь:** `pubspec.yaml`, підписи в інтерфейсі, перевірка оновлень, назва iOS-артефакту.

### Файли для завантаження

- **Android:** `mizik429V6.1.0_Android.apk`
- **Windows (інсталятор):** `muzik420_setup_v6.1.0.exe`
- **Windows (.portable exe):** `muzil420V6.1.0_Windows.exe`
- **iOS (unsigned IPA з Codemagic):** `muzik420_unsigned_v6.1.0.ipa`

### Як встановити

- **Android:** завантаж APK, дозволь встановлення з невідомих джерел, відкрий файл.
- **Windows:** запусти `muzik420_setup_v6.1.0.exe` (або просто `muzil420V6.1.0_Windows.exe` без інсталяції).
- **iOS:** unsigned IPA встановлюється через Sideloadly / AltStore / Apple Developer (залежно від сертифіката).

### Перевірка оновлень у застосунку

Старі версії (6.0.x і нижче) знаходять цей реліз автоматично:
Налаштування → Перевірити оновлення → «Доступне оновлення», де показані поточна версія, версія релізу, платформа та посилання на цю сторінку.
```
